# 📂 Aula 03: GitHub e Controle de Versionamento

Este diretório é dedicado ao aprendizado prático de versionamento de código e à ambientação com a plataforma GitHub. 

---

## 📝 Conteúdo Estudado

- Controle de versionamento e GIT
- GitHub
- Criando um repositório no GitHub

---

## 🛠️ Atividades e Testes Realizados

Os arquivos contidos nesta pasta possuem o objetivo de **testar as funcionalidades do GitHub** e do Git. 

A atividade desta aula consistiu em:
1. Criar e configurar uma conta na plataforma do GitHub.
2. Criar um repositório público originalmente nomeado como `Tarefas_LPR`.
3. Realizar os primeiros comandos de versionamento locais (Git) e remotos (GitHub).
4. Subir os arquivos de código desenvolvidos previamente na Aula 2 para consolidar e validar o fluxo de trabalho com commits e pushes.
