# 📂 Aula 06: Funções

Este diretório contém os exercícios práticos desenvolvidos para exercitar a modularização de código por meio de funções, abordando a passagem de parâmetros e o retorno de valores utilizando as linguagens C# e C++.

---

## 📝 Conteúdo Estudado

- Funções
  - O que são funções?
  - Sintaxe de uma função
  - Parâmetros
  - Retorno

---

## 💻 Exercícios Práticos

Abaixo estão as descrições exatas e as tabelas de exemplo fornecidas para cada exercício da tarefa:

### 📐 Exercício 1: Área do Retângulo
Crie uma função que receba a base e a altura de um retângulo e retorne a sua área.

| ENTRADA | SAÍDA |
| :---: | :---: |
| 5 e 2 | 10 |

### 🌡️ Exercício 2: Conversor de Temperatura
Crie uma função que converta uma temperatura de Celsius para Fahrenheit.
* **Fórmula:** $F = C \cdot 1.8 + 32$

| ENTRADA | SAÍDA |
| :---: | :---: |
| 0 | 32 |
| 100 | 212 |
| 30 | 86 |

### 🔍 Exercício 3: Verificação de Número Primo
Crie uma função que receba um número inteiro e retorne verdadeiro se o número for primo e falso caso contrário.

| ENTRADA | SAÍDA |
| :---: | :---: |
| 2 | true |
| 4 | false |
| 7 | true |

### ⏱️ Exercício 4: Conversão de Tempo
Faça uma função que receba um único valor contendo o tempo de duração de um experimento expressado em segundos. A função deverá converter esse tempo e exibi-lo formatado em horas, minutos e segundos.

| ENTRADA | SAÍDA |
| :---: | :---: |
| 3600 | 1h 0m 0s |
| 3661 | 1h 1m 1s |
