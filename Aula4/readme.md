# 📂 Aula 04: Estruturas de Seleção

Este diretório contém os exercícios práticos desenvolvidos para exercitar a implementação das lógicas condicionais e de seleção utilizando as linguagens C# e C++.

  - SWITCH

## 💻 Exercícios Práticos

Abaixo estão as descrições e os exemplos de entrada e saída esperados para cada exercício da tarefa:

### 🔢 Exercício 1 (C#): Verificação de Par ou Ímpar
Fazer um programa para ler um número inteiro, e depois dizer se este número é par ou não.

| ENTRADA | SAÍDA |
| :---: | :---: |
| 10 | PAR |
| -15 | ÍMPAR |
| 0 | PAR |

### ✖️ Exercício 2 (C++): Múltiplos entre Si
Leia 2 valores inteiros (A e B). Após, o programa deve mostrar uma mensagem "Sao Multiplos" ou "Nao sao Multiplos", indicando se os valores lidos são múltiplos entre si.  
*Atenção: os números podem ser digitados em ordem crescente ou decrescente.*

| ENTRADA | SAÍDA |
| :---: | :--- |
| 2 18 | Sao Multiplos |
| 6 25 | Nao sao Multiplos |
| 36 6 | Sao Multiplos |

### ⚔️ Exercício 3 (C#): Mecânica de Habilidades de RPG
Suponha que você está desenvolvendo um jogo de RPG. Você é responsável por implementar a mecânica de habilidades especiais para diferentes classes de personagens. Cada classe tem suas próprias habilidades especiais. Crie um programa que permita ao jogador escolher uma classe de personagem e, em seguida, exiba suas habilidades especiais correspondentes.

| CLASSE | HABILIDADES |
| :--- | :--- |
| Guerreira | Ataque Pesado, Defesa Total |
| Mago | Bola de Fogo, Escudo de Gelo |
| Arqueira | Flecha Precisa, Disparo Triplo |
